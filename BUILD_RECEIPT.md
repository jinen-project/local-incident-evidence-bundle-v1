# Build receipt

Product: Local Incident Evidence Bundle v1. Reused components are Local Receipted Handoff v1.0.0 (`d0535953b193394db0dc40a1c4f6faf86245421a`, MIT) through its observed exported handoff function, and Evidence Packet v1.0.0 (`e0e288ae924402593c42e46c1e10724aeec0c126`, MIT) through its documented CLI. No sibling path is used at runtime.

The live demo observed three formed events, one matched NOT_FORMED event with zero journal mutation, and one replay with zero second journal mutation. The final bundle contains an NDJSON journal, deterministic source-time/local-sequence timeline, Evidence Packet JSON/Markdown, review Markdown and bundle index. It does not prove causation, root cause, resolution, externally verified time/truth, or complete history.
